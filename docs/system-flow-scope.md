# プロジェクト内のシステムフロー理解に絞る

決定日：2026-10-21。利用者によるスコープ指定に基づく方針変更。

## 解消したい読解上の問題

関数やモジュールを個別に読めても、一つの入力が処理をまたいで結果になる過程をつなげにくい。途中のデータや状態を記憶しながら、全体図・個別の図・ソースを照合する負担がある。

| 判断項目 | 今回の方針 |
| --- | --- |
| 対象の問い | このプロジェクトで、ある操作・リクエスト・イベントがどこを通り、何を変え、どこで終わるか |
| 現在の困難 | 全体と部分の照合、途中状態の保持、分岐・待機・非同期の追跡 |
| 改善の仮説 | 固定配置の全体アニメーションと、同じ経路・段階の詳細を同期すると、処理を頭の中でつなぐ負担が減る |
| より簡単な方法 | 静的フロー図と値の前後表でも説明できる。短い問いでは簡素にし、HTMLを出せない環境では静的表現を使う。HTMLでも停止状態で内容を読めるようにする |
| 正確さへの影響 | 説明順が実行順に見える、キュー登録が完了に見える、外部の内部実装を想像で埋める危険がある。主体の境界・根拠の種類・未確認箇所を明記する |
| 評価方法 | 未提示の条件で、到達する段階・変わる状態・到達しない段階を予測できるか。生成物の照合と利用者の理解評価を分ける |
| 追加コスト | 対象フローの調査、状態モデル・表示・分岐の実装、再生や移動の検証。網羅的な自動解析や汎用描画基盤は今回の要件にしない |
| 採否・撤回条件 | 正確な経路が示せ、静的説明より理解または照合負担が改善するなら継続。根拠不足なら説明範囲を縮小。演出が誤解や操作負担を増やすなら縮小・修正 |

## 具体化した境界

- 一つの利用場面を単位にする。開始点・入力例・終了点・調査範囲を表示する。
- 正常経路と、その問いに関係する分岐を扱う。全機能・全分岐の網羅は求めない。
- 各段階に主体、入力、処理、出力・状態、次へ進む条件、ソース参照を対応付ける。
- 全体と詳細の段階・経路・状態を同期する。再生位置を戻す場合も、その段階の状態を再構成する。
- 説明の再生で対象システムを動かさない。モデル上の計算結果と、実行観測を区別する。
- 概念比較はフローの理解に必要な補足に限定する。一般教材の生成へ戻さない。

## 理由・根拠・既存機能への影響

利用者は、図を動かすだけの試作には不足を感じ、Transformerの全体アニメーションと詳細の組み合わせを評価した。その後「プロジェクト内のシステムフローを理解するため」と明示した。この反応は特定の利用者による試作への観察であり、理解成績の改善を測定した結果ではない。

従来の「二概念を同じ操作で比較する」手順を、プロジェクトの入口から実装をたどる手順へ置き換えた。全体図・詳細・動きは利用者の希望に基づく設計方針。視覚思考者の定義、正確さ優先、根拠の区別は維持した。既存のHTML試作は検討資料として保持し、現行Skillの配布指示からは依存しない。旧コピーと参照のMarkdownも過去の資料として残す。

## 確認と未検証事項

説明手順をシステムフロー用に更新し、GUIDELINES・AGENTS・READMEの対象範囲を揃えた。実行観測の区別、原資料の参照、非同期の未指定順序、HTML再生による実処理の抑止が手順に含まれることを確認した。

従来参照されていた `evals/README.md` は作業ツリーに存在しなかったため、今回の範囲に合う代表課題と採点基準を新規に整備した。課題の入力と正答集は分離した。今回の文書作成では正答集を読めるため、独立した生成評価とは扱わない。

今回の確認結果：

- skill-creatorの `quick_validate.py`：`Skill is valid!`。
- `npx skills add . --list`：更新した説明で `i-am-visual-thinker` を1件検出。
- `node evals/check-cases.cjs`：早期終了、登録とワーカー処理、キャッシュの各経路の教材整合性チェックが成功。
- 更新したMarkdownのローカル参照15件が解決できることを確認。
- 差分の空白確認は、既存のMarkdown改行用の行末空白を許容して成功。

その後、[linkdingの初回生成評価](../evals/runs/linkding/report.md)を実施した。対象を読み取りだけで調べてHTMLを生成し、原資料・既存テストの記述との照合と、生成物のブラウザ操作を確認した作成者レビューである。対象アプリの実行観測、人による経路の説明・予測・適用、所要時間や負担の比較は未実施。動作確認結果を、実プロジェクトでの理解支援効果へ一般化しない。
