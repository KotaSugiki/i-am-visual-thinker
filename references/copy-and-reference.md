# 出力例：コピーと参照

この例は、同じ具体例・配置で比較し、一つの操作から差を見せるための参考。利用者への説明は以下の粒度を目安にする。

---

ここでは「コピー」を、中の数値も独立した別の箱を作ること、「参照の共有」を、同じ箱に二つの名前を付けることとして比べます。プログラミング言語ごとのコピーの仕様や、箱の中にさらに箱がある場合は扱いません。

`a` と `b` は名前、`#1` と `#2` は箱の識別子、矢印は「その名前が指す箱」を表します。

最初は、どちらも `a` から見ても `b` から見ても数値は `1` です。

```text
コピー                            参照の共有

a ──→ [#1: 1]                    a ──→ [#1: 1]
                                       ↑
b ──→ [#2: 1]                    b ────┘

箱は二つ                          箱は一つ
```

ここで、両方に同じ操作をします。

**「b が指す箱の中身を 2 に書き換える」**

```text
コピー                            参照の共有

a ──→ [#1: 1]                    a ──→ [#1: 2]
                                       ↑
b ──→ [#2: 2]                    b ────┘

#1 はそのまま、#2 を変更           共有している #1 を変更
```

| 見る場所 | コピー | 参照の共有 |
|---|---|---|
| a から見える数値 | 1 → 1（同じ） | 1 → 2（変更） |
| b から見える数値 | 1 → 2（変更） | 1 → 2（変更） |
| 名前と箱の接続 | 同じ | 同じ |

**違いは、同じ数値が入っているかではなく、同じ箱を指しているかです。** 参照の共有では、b を通じて書き換えた箱を a も見ています。b から a へ数値を送っているわけではありません。

最後に、別の操作を予想してみてください。上の操作後の状態から、今度は **a が指す箱の中身を 7 に書き換える**と、b から見える数値はどうなるでしょう？

| 選択肢 | コピーの場合 | 参照の共有の場合 |
|---|---|---|
| A | 2 | 7 |
| B | 7 | 7 |
| C | 2 | 2 |

A・B・C のどれかで答えられます。
