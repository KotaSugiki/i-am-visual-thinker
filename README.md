# i-am-visual-thinker

視覚的に考えたい人が、混同しやすい概念の違いを理解するためのSkill。

初期版は「AとBの違いがわからない」という場面を対象にします。同じ構図で二つの概念を比べ、同じ操作を加えたときに結果がどう分かれるかを見せます。その後、別の条件で結果を予想してもらい、理解を確かめます。

## 初期版の体験

1. **比べる** — 同じ例・配置・記号で、共通点と違いを見つける。
2. **変化を見る** — 条件を一つ変え、変わった場所と変わらなかった場所を追う。
3. **予想する** — 別の例で結果を選ぶ、指す、図を直すなどして理解を確かめる。

図の種類を増やすことより、違いが現れる具体例と操作の選び方を重視します。まずは静的な図の操作前・操作後でも成立する設計です。対話的な表示が使える環境では、同じ比較を操作できる形にできます。

## 依頼の例

- 「コピーと参照の違いを、片方を書き換えたときの変化で見たい」
- 「平均値と中央値の違いを、一つの値だけ大きくした例で理解したい」
- 「必要条件と十分条件を混同する。具体例を変えながら見分けたい」

## ファイル

- [SKILL.md](SKILL.md): Skillの適用条件と説明の進め方。
- [コピーと参照の出力例](references/copy-and-reference.md): 同じ配置で比較し、違いが出る操作を示す例。

理解できたかの目安は、説明の図を見直せる状態で、別の例の結果を予想し、違いが生じる箇所を示せることです。特定の認知特性や、すべての利用者に共通する学習方法を前提にせず、本人の反応に合わせて表現を調整します。
