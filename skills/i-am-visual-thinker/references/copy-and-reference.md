# 出力例：コピーと参照

この例は、同じ具体例・配置で比較し、一つの操作から差を見せるための参考。利用者への説明は以下の粒度を目安にする。

---

ここでは、同梱の教材コード [copy_reference.py](copy_reference.py) の `copied` と `shared` を比べます。数値一つを持つリストを箱として示し、リストをコピーする場合と、同じリストを参照する場合を扱います。入れ子の要素のコピーや、ほかの言語の仕様には一般化しません。

以下はコードの静的読解による説明です。初期値は `initial=1`、書き換える値は `replacement=2` です。

`a` と `b` は名前、`#1` と `#2` は箱の識別子、矢印は「その名前が指す箱」を表します。

箱番号は図のために付けた番号です。左右は別々の関数の実行を表し、同じ番号でも左右で実体を共有していません。

| 図の要素・関係 | 原資料の箇所 | 根拠の種類 |
|---|---|---|
| コピー側の別々の箱 | [copied](copy_reference.py) の `a = [initial]` と `b = a.copy()` | 静的読解 |
| 参照側の一つの箱と二つの名前 | [shared](copy_reference.py) の `a = [initial]` と `b = a` | 静的読解 |
| 箱の中身の変更 | 両関数の `b[0] = replacement` | 静的読解 |

`b[0] = replacement` の直前は、どちらも `a` から見ても `b` から見ても数値は `1` です。

```text
コピー                            参照の共有

a ──→ [#1: 1]                    a ──→ [#1: 1]
                                       ↑
b ──→ [#2: 1]                    b ────┘

箱は二つ                          箱は一つ
```

ここで、両方に同じ操作をします。

**「b が指す箱の中身を 2 に書き換える」**

```text
コピー                            参照の共有

a ──→ [#1: 1]                    a ──→ [#1: 2]
                                       ↑
b ──→ [#2: 2]                    b ────┘

#1 はそのまま、#2 を変更           共有している #1 を変更
```

| 見る場所 | コピー | 参照の共有 |
|---|---|---|
| a から見える数値 | 1 → 1（同じ） | 1 → 2（変更） |
| b から見える数値 | 1 → 2（変更） | 1 → 2（変更） |
| 名前と箱の接続 | 同じ | 同じ |

**違いは、同じ数値が入っているかではなく、同じ箱を指しているかです。** 参照の共有では、b を通じて書き換えた箱を a も見ています。b から a へ数値を送っているわけではありません。

最後に、別の操作を予想してみてください。上の操作後の状態から、今度は **a が指す箱の中身を 7 に書き換える**と、b から見える数値はどうなるでしょう？ これは原資料の操作に続けて `a[0] = 7` を行う、説明用の追加条件です。

| 選択肢 | コピーの場合 | 参照の共有の場合 |
|---|---|---|
| A | 2 | 7 |
| B | 7 | 7 |
| C | 2 | 2 |

A・B・C のどれかで答えられます。
